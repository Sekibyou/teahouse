# 插件目录

将插件文件夹放入此目录，启动后端时自动发现。

## 什么是插件？

插件可以扩展 Teahouse 的功能，包括：

- **导演工具**：为 AI 导演新增可调用的工具（如生图、语音合成、联网搜索）
- **前端面板**：提供设置界面，配置 API key、URL 等参数
- **加密数据**：每个插件有独立的加密存储空间，其他插件无法访问

## 如何使用？

1. 将插件文件夹放入此目录
2. 重启后端，或在「设置 → 管理插件」中刷新
3. 在插件管理页面启用插件
4. 如果插件有配置面板，点击「打开配置面板」填写参数
5. 在游玩时，导演即可调用插件提供的工具

## 插件结构

```
my-plugin/
  plugin.json      必需 — 元数据、权限声明、工具定义
  backend.py       可选 — 后端钩子和工具执行器
  frontend/        可选 — 前端配置面板
    index.html
```

详见 `tests/sandbox-design.md` 中的插件系统设计文档。

## 内置测试插件

开发阶段可使用 `mock-service` 插件测试插件系统：
1. 复制 `tests/mock-service-plugin/` 到此目录
2. 启动 mock echo 服务：`python tests/mock_echo_server.py`
3. 在插件管理中启用并配置 token
