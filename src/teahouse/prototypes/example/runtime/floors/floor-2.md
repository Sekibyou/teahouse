# 第二章 · 酒馆夜话

暮色渐深，主街上唯一那家酒馆点起灯来。木门半掩着，透出昏黄的光和嘈杂的人声，混着一股麦酒与炭火交织的热气，顺着门缝往外飘。

${user}推门走了进去。屋里比他想象中热闹，十来张粗糙的木桌散坐着几拨人，屋角燃着一炉火，把整间屋子的影子拖得长长的。他找了吧台角落的位置坐下，还没来得及开口，就先听到邻桌的动静。

「……我跟你说，底下那第三层，我去过！那地牢里头的妖物，寻常刀剑砍上去，跟砍铁块似的，蹦火星子儿不听使唤。」一个络腮胡子的大汉喝得半醉，嗓门不小，「真要发了横财的，还得往下了——可再往下，嘿，命就不归自己管咯。」

「得了吧你，就你那两下子，第三层也是捡回来的命。」同桌的人哄笑。

「你们懂个屁！老子好歹下去过，你连地牢门朝哪开都不晓得！」

酒馆里大部分人只顾低头喝酒，只有零星几桌压着声音议论地牢里的传闻。有个佝偻的老头儿靠在墙角，端着半碗温酒，慢悠悠地插了一句：

「老五……昨天一早下去的，到现在还没见着人回来。」他垂下眼帘，声音很轻，「唉。白瞎了一身好本事。」

那一桌安静了一瞬，随后有人硬着头皮打了个哈哈：「老五那人精着呢，肯定没事，兴许是在底下多淘了两天货。」话虽这么说，谁的眼神都没那么笃定。

${user}倚着吧台，要了一杯最便宜的麦酒。麦酒粗糙，带点涩味，但这一程风尘奔波下来，滚进喉咙里倒也熨帖。他一边喝，一边竖起耳朵，把那些七零八碎的消息一点一点拼进脑子里：

　01. 地牢越往下，越可能有值钱的东西，也越凶险，一般人只敢在头几层转转；
　02. 镇上有个行脚铁匠，专给人做成套的装备、修补兵器，手艺不错，收费不便宜；
　03. 冒险者公会在镇西头，登记入会不收钱，新人都从那领第一份委托，但抽成两成；
