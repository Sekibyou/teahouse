# 第三章 · 公会灯火

夜色彻底落了下来。酒馆里的人渐渐散了，有人披衣回屋，有人三三两两结伴往镇西头走——大概是趁着天还没全黑，先去公会碰碰运气。

吧台后的老板娘一直在默默擦着杯子，这会儿抬眼瞟了${user}一眼，没急着搭话，只把那只酒盅又轻轻推过来一点。镇上的规矩，新来的人，别人不催你，你自己心里得先有个数。

${user}谢过，把酒又呷了一口。他这一路翻山过河，身上没几个子儿，那把旧短剑的边缘也豁了几处。原本只想着找个像样点的镇子补补给、歇口气，再琢磨往后往哪走。可这一屋子听下来，倒让他心里那根弦无端地绷了起来。

窗外，镇西头的公会灯火通明，隐约能看见有人扛着灯，三三两两往山那边去。夜色把一切都笼上一层灰。

他低头看着手里的半杯酒。行囊里有干粮、一把老旧的短剑，和一张不知从哪里弄来的、边角已经毛糙的旧地图。他本可以今晚就在镇口的老槐树下对付一宿，省下那几枚铜板；甚至明天一早从另一条路继续赶路，把这座灰石镇抛在身后——毕竟，他原本并不一定要在这里停留。

可他想起那个佝偻老头儿的话，想起那句「多少人进去，就再没出来过」，想起酒馆里那些一半吹牛、一半听来的地道消息。

酒杯空了。老板娘伸手来收，随口问了一句：「住店？还是……这就走？」

${user}的目光，穿过窗，落在镇西头那片通明的灯火上，停了很久。

——接下来，要怎么走？
