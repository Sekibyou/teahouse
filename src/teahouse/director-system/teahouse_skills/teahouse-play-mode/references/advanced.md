# 进阶操作：`BatchGenerate`

`BatchGenerate` 一次发起多个**互相独立**的正文生成，并行跑，全部结束后聚合返回。各步落各自的路径，**不共享上下文**——所以产出是真正独立的，不会互相迁就趋同。

这与「让正文模型顺手编一下」有根本区别：正文模型一次生成只走一条路径，而路人、物品、随机事件这些**本该由骰子决定**的东西若交给它顺手编，会带着惰性往套路走、彼此也趋同。拆成独立并行生成，每一样都各自成形。

## 参数与行为

- **`steps`**：数组，最多 8 步。每项参数与 `Generate` 相同——`source_file`（yaml 配置）与 `path`（输出文件）必填，`overwrite` / `reasoning_effort` 可选。人设与任务写在各步自己的 yaml 里，前置信息用 `{{}}` 切片或 `${}` 变量引用。
- **返回只有「路径 + 成败」，不带正文**——要读内容自己 `Read`。失败的步不连坐其余步，可单独重发 `Generate` 重试。
- **默认关闭思考**（`reasoning_effort` 不传 = `none`）——为快速反应而设；这点与单发 `Generate` **相反**（那边不传 = 用提供商的默认配置）。要思考就按步显式传 `low` / `mid` / `high` / `max`。
- **落点一律 `temp/`**：旁路素材不进正文历史、不进 git。

## 一、小说模式：正文之前的「素材先行」

正文产出之前，先把这一章要用到的**临时人 / 物 / 地点 / 势力**与**随机走向**并行产出来，再决定留哪些进设定。

1. **写 yaml**：每步一个，人设与任务写在 `system:` 段，落 `temp/gen/<名字>.yaml`。例如「临时路人：酒肆里正在争论的两个镖师」「临时物品：拍卖会上来路不明的一件漆器」「本章的三种可能走向」。
2. **一次下发**（≤8 步），各自落 `temp/gen/<名字>.md`。
3. **挑选与转写**：`Read` 回来，把要用的写进 `settings/dyn_settings/` 的对应板块，并按「临时设定」的约定标 `${@note ...}` 生效周期。
4. **接进正文**：组装器 `settings/assemble.md` 引用这些设定（整文件或锚点切片），正文模型就看到了。

要点：

- **落 `temp/` 是刻意的**——没被选中的就烂在 temp/（不进 git、不影响正文），选中的才转写进 `dyn_settings/`。
- **要「多个备选」就同一份 yaml 多下发几次**（不同 `path`），再挑一条。
- **它产的是素材，不是正文**。正式正文仍走 `generate-config/*.yaml` → `Generate`（或沙盒的生成流水线）。
- **可以自动化**：沙盒的生成流水线也能经 `runTool` 调 `BatchGenerate`，读回落盘结果后拼进 user 消息（例如拼成「角色 A 的行动为…；本轮可能出现的随机事件为…」再交给正文模型）——这条路由实例的沙盒代码驱动，完全不经过导演。

## 二、跑团模式（DM 式）：独立扮演与临场素材

DM 是持续对话的主持人，最需要的就是**快**与**不趋同**。三种用法：

1. **多角色各自独立行动（强隔离）** —— 追求真实 reaction 就不能在一个上下文里同时演所有人，那样他们会互相迁就。做法：每步一个角色的 yaml（人设写在 `system:` 段），一次 `BatchGenerate` 并行产出一批**独立行动**，DM 再读回来汇总、推动剧情。
   产出落 `temp/` 还有个好处：DM 能用 `Output` 的 `{{}}` 切片**直接引用**呈现（引用前还能 `Edit` 微调或切片裁剪）——同一轮内「先并行产出 → 再引用呈现」即可闭环，不必把长文本整段复制进工具参数。
2. **同时产出多个备选** —— 同一份 yaml 下发几次，挑最合适的。
3. **增加活人感的临场素材** —— 每回合随机产生：几个随机事件（由 AI 现产，而非预设死清单）、偶遇的路人或配角、拍卖会上出现的某件物品。这些都给一份**简单临时设定**落 `temp/`，需要时引用进来。

因为默认 `thinking=none`，这些旁路生成不会拖慢对话节奏；真要某一步多想，按步传 `reasoning_effort`。

## 三、和 `runTool` 的分工

| | `runTool` | `BatchGenerate` |
|---|---|---|
| 谁发起 | **沙盒代码** | **导演 / DM**（LLM 侧） |
| 步骤 | 内联工具数组，可以是任意工具 | 只有正文生成 |
| 形状 | 每批一个后台任务，批内各步**串行** | 一次调用内部**并行**扇出 |
| 返回 | 每步一条 `tool_run` 事件 | 聚合成**一条** tool result |

`BatchGenerate` 不改变「同一轮多个 tool call 串行执行」的既有语义——并发被关在这一个叶子工具里。
