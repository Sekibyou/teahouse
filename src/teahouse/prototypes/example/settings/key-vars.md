## 当前可维护变量清单

${@note 
  > 本文件是**作者维护的变量清单**：声明哪些变量需要被正文 AI 看到并维护、如何维护。与剧情强相关，
  > 由作者按本实例实际变量增删。默认不随 Generate 引用（组装器里以注释形式给出，需要时启用）。
}

在修改以下变量时你需要生成 JSON，以下是这些变量的名字、当前类型/边界、当前值、和说明：

```yaml
- name: user
  value: ${user}
  type: ${@type user}
  note: 玩家主控角色的名字
- name: user所在地
  value: ${user所在地}
  type: ${@type user所在地}
  note: 主角当前所在地。在主角移动之后需要用`set`更新此变量。
```

${@note 
    维护说明（导演可见，正文 bot 看不到）：在此按实例实际变量增删清单行；${变量名} 是占位符，Generate 发送前会自动展开为当前值，正文 AI 据此计算。变量名必须与 runtime/runtime_vars.jsonl 中的实际名字一致，否则操作会落到不存在的变量上。
}

${@note 
    建议在note字段里描述变量变动时机，条件，以及值。note字段可用${...}和{{...}}语法
}

${@note 
    （如需正文在章末给玩家产出可选项「文末选项」）参考示例文件 `settings/key-vars-withOption-example.md`：该文件演示了如何在本清单注册变量、并在清单外给出选项的产出要求与判定标记格式；照它的写法把对应行/段落并入本文件即可让正文 bot 维护文末选项。
}
