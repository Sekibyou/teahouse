# `${}` 表达式语法

`${...}` 是**变量命名空间**：括号内是变量名或条件表达式，一律**裸写**，无需再加任何包裹。它出现在所有「喂给 AI」的表面（导演系统提示词组装 + Generate 发送给正文模型前 + DM 组装），解析时就地展开为值。

**`${}` 严格匹配 `\${...}`；裸 `$` 不处理。变量不存在 → 原样显示（不报错、不删）。**

## 变量引用

- `${金币}` —— 变量值
- `${user}` —— 普通变量（`user` 直接裸写，不加任何包裹）

**变量命名限制**（违反会被后端 `validate_var_name` 拒绝；沙盒 `Teahouse.setVar()` 只是经宿主机转发到**同一个**后端接口，没有第二套校验）：

- **禁空白**（空格/tab/换行）——代码块里 `if dice == 6` 要求变量名是合法 Python 标识符
- **禁冒号 `:`** —— 会让裸 `${}` 被判定层误判为 condition（`${a:b}` → 取 `a`/`b` 作条件）
- **禁 `@`** —— 它是 `${@name}` 显式指令的保留前缀
- **`teahouse.` 是系统保留命名空间**，`setVar`/`SetRuntimeVar` 禁用其命名（会告警忽略）

## 显式占位符（注册式框架 `${@...}`）

除裸写外，还可用 `@` 前缀的独立指令精确表达语义，全部统一进一个判定框架：

| 写法 | 含义 |
|---|---|
| `${@var 金币}` | 变量值（与裸写 `${金币}` 等价） |
| `${@type 金币}` | 变量的**类型串**（`number`/`string`/`boolean`/`array`），喂给正文 AI 判断类型用 |
| `${@python return ...}` | 白名单 python 代码块，须含 `return` |
| `${@condition 好感度 >= 80: "{{xxx.md}}"}` | **最简条件切片**（见下） |
| `${@note 任意文本}` | 注释，解析时恒剥为空（正文 AI 看不到，导演 Read 可见）——**详见行为准则** |
| `${@max [1,9,5]}` / `${@min [...]}` / `${@len [...]}` | 从字面量列表或数组变量取 max/min/len |
| `${@random ["口粮", "回血药"]}` | 从**给定列表里随机挑一项** |
| `${@mention 黄泉剑\|妖剑, 传闻: "{{...}}"}` | **关键词灯**（见下） |

### `${@condition}` —— 最简条件切片

```
${@condition 好感度 >= 80: "{{xxx.md}}" else "{{yyy.md}}"}
```

- **冒号前**是条件（python 比较式，如 `好感度 >= 80`、`dice == 6`）；**冒号后**是真输出，**`else` 后**是假输出。
- `if` / `else` 两个词**都是可选的**；**`else` 后绝不写冒号**（直接跟内容）。它们只是占位说明词，别把元语法（方括号等）写进括号。
- 输出是 return 值：带引号字面量 `"{{xxx.md}}"` / `"达标"`、裸变量名 `金币`、函数 `roll("1d10")`、裸切片 `{{file:10-30}}`。引擎自动封装成 `if 条件: return 真 else: return 假`。
- **不支持 elif / 三元**——多档位阶梯用 `${@python}`（下节）。
- 裸写 `${好感度 >= 80: "..."}` 等价（自动判为 condition）。

**结果三态**：条件真 → 真输出；条件假且有 else → 假输出；**条件假且无 else → 返回空**（不注入任何内容，不是残留原文）；**坏块**（无冒号、语法错、变量不存在）→ **原样保留**便于排查。

### `${@python}` —— 多档位阶梯

需要「按变量值从几段里就地选一段」且**三档及以上**时用：

```
${@python return "{{settings/dyn_settings/heartful-zhongqing.md}}" if 好感度 >= 80 else ("{{settings/dyn_settings/heartful-xindong.md}}" if 好感度 >= 50 else "{{settings/dyn_settings/heartful-chujian.md}}")}
```

`return` 的值也可以是别的占位符（`{{file:line}}`、`${变量}`），会继续被后续解析展开。也可写成多行块：

```
${
if dice == 6:
    return "{{room1.md}}"
else:
    return "{{room2.md}}"
}
```

未命中的分支不进入上下文。

### `${@mention}` —— 关键词灯（按需注入散碎设定）

```
${@mention 黄泉剑|妖剑, 传闻: "{{settings/static_settings/legend.md}}"}
```

冒号前是逗号分隔的多个**正则**；一旦这轮生成发给 AI 的**整个消息序列里别处**（system/user/assistant 任一台词的正文）提到任一关键词，就命中并输出冒号后的内容；**全程没提 → 最终销毁不留脏文本**。适合"数量多、每条小、按需才注入"的设定（传说道具/武器/传闻/配角，可几十条放一个大 `.md`，由 `@mention` 命中才整段注入）。

- **匹配范围是整个 payload 的所有消息**（跨消息多轮，每轮以"上一轮"拼接正文为匹配源），所以 system 里挂的 `@mention` 能看到 user 正文里写的词。
- **匹配源在 Generate 路径会先剥掉所有最外层占位符外壳**（`${...}` / `{{...}}` 的字面量，含 `${@note ...}`）——只对"真正会进正文的内容"做关键词判定，文件名/指令名/注释里的字不会误触发。
- **冒号后的输出是值表达式**（同 `@condition` 的 return 值）：`"{{legend.md}}"`→展开切片、`"达标"`→字符串、`好感度`→变量值、`[1,2]`→数组。
- 坏块（无冒号/无关键词）→ 原样保留便于排查。
- **⚠️ 易踩坑**：匹配是**全局**的且**只认裸写正文**——所以**别让触发词出现在裸露的说明/叙述文字里**（比如说明"此片段触发'黄泉剑'"就会让"黄泉剑"恒定命中、永不销毁）。若某段话只想当注释、不进匹配源，用 `${@note ...}` 包起来。

**适用范围（两个解析面有差别，别一概而论）**：

| 解析面 | 匹配源 | 未命中的 `@mention` |
|---|---|---|
| **Generate 跨消息面**（发给正文模型前） | 整个 payload 所有消息**剥壳后**的正文拼接 | 保留到最后一轮**统一销毁** |
| **其它组装面**（导演系统提示词等单文本解析） | **该文本自身，不剥壳** | **就地销毁** |

两面的共同点：**只认裸写正文**——所以上面那条"别把触发词写进裸露说明"对两面都成立。

**未注册的 `@xxx` → 原样保留不报错；变量/路径不存在 → 原样保留。**

## 语法要点

- 块内是**标准 Python**——字面量布尔必须写 `True`/`False`（大写，小写 `true` 是未定义名，会整块残留）。
- **单行 if 链有引擎兜底但也最不抗造**：`if a: return x elif b: return y else: return z` 这种单行多分支，引擎会拿 token 驱动重写成合法多行（`_rebuild_single_line_if`），但前提是那行**原封不动**进了 Python 解析。**多分支一律写多行块**（`return "a" if cond else "b"` 这种单行三元可留），别依赖单行兜底。
- 块内**可以定义局部变量**（仅本次块内有效，返回即弃，绝不写回沙盒变量）。骰子结果存起来再拼进返回句子时，用 f-string 插值数值、`{{切片}}` 放 f-string **外面**用 `+` 拼接（f-string 会把 `{{` 转义成字面 `{`，切片不能写在花括号内）：

```
${
result = roll("1d6")
if result >= 5:
    return f"当前骰子结果是{result}。" + "{{settings/dyn_settings/encounter.md}}"
else:
    return "未触发特殊遭遇"
}
```

- **排查用三态**：`@condition` 假条件 → 该位置变**空**（正常）；**坏块**（语法/越权/变量不存在）→ **整块原样残留**（说明写错，需改）。产出 payload 后检查是否有未展开的 `${ if... }` / `${@...}` 残留。

## `roll()` 骰子语法

块内可调用白名单函数 `roll("XdN")`。支持 RPG 语法：

- `XdN`（如 `1d6`、`2d10`）
- 行末 `+N` / `-N` 修饰（如 `2d10+5`）
- `k` 取最高（`4d6k3`）、`dl` 去最低（`4d6dl1`）
- `r` 重骰 / `ro` 重骰一次（`3d6r1`）
- `e` / `!` 爆炸、`p` 穿透

非法表达式会**原样保留不报错**。沙盒侧 `Teahouse.roll()` 复用**同一套语法**（单一事实源）。

**只想要一个数字时一律丢骰子**：`${@python return roll("1d10")}`。`${@random [1..6]}` 这种范围写法**不支持**，`[1,6]` 也只是从「1 或 6」二选一、不是「1 到 6 随机取数」。

## 转义

在开括号前加反斜杠 `\`，强制该占位符保持**字面量**、不解析：

- `\${name}` → `${name}`
- `\$ { if...: }` → 不执行的条件块
- `\{{path}}` → `{{path}}`（`{{}}` 规则详见行为准则）
- `\\` **不会**被折叠成 `\`——反斜杠只在**紧跟 `{` 或 `$` 时**才被消费掉；其余位置的反斜杠原样保留（`\\{{path}}` 的结果是 `\{{path}}`：第一个 `\` 留下，第二个 `\` 吃掉、切片得以保持字面量）

反斜杠在**解析全部结束后**才被去掉还原，故多轮交替展开期间也不会被吞。

## `${teahouse.*}` 系统内部值

如 `${teahouse.behavior}`、`${teahouse.tools_usage}`、`${teahouse.file_tree}`、`${teahouse.available_skills}`，以及**每轮动态**的 `${teahouse.user_input}` / `${teahouse.usage}` / `${teahouse.big_files}`（**仅 `user_tail` 内有效**）。这些在整套占位符解析**结束之后**做一次正则替换植入为**字面量**——其内容里的 `{{...}}`/`${...}` **不会被二次展开**，源文件**无需转义**、裸写即可。
