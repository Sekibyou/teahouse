# 正文变量维护指南

## 如何生成 JSON 修改变量

当本章剧情发生了需要记录的数值/状态变化（获得/消耗、关系变化、状态标记等）时，在正文**最末尾**追加一个 HTML 注释块记录，格式：

```
<!-- teahouse-vars: [
  {"type": "set",   "name": "变量名", "value": 值},
  {"type": "add",   "name": "变量名", "value": 数值},
  {"type": "append","name": "变量名", "value": 值},
  {"type": "pop",   "name": "变量名", "value": 值},
  {"type": "x",     "name": "变量名", "index": 序号, "value": 值}
] -->
```

### 操作语义

| `type` | 合法目标 | 语义 |
|---|---|---|
| `set` | boolean / string / number / array | 整体覆盖；变量不存在则自动创建 |
| `add` | number | 现值 = 现值 + value；未设按 0 起加 |
| `append` | array | 尾部追加 value |
| `pop` | array | 按值移除第一个匹配项 |
| `x` | array | index 处整体替换；index 可负；越界失败 |

### 规则

1. 只维护 boolean / string / number / array 四类值；数值增减用 `add`，数组增删用 `append` / `pop`，指定位置替换用 `x`，其余用 `set` 整体覆盖。
2. 只记录剧情中确实发生变化、且对后续有影响的量；**没有变化就不要输出这个块**。具体需要追踪和维护的变量，以及维护规则请见下面的 `## 当前可维护变量清单`。
3. 块建议插入正文里，在变量发生变动之后立即修改。例如：（要求对金币变量进行维护）描写了一段主角购物，给了钱，然后立马插入一个块用 `add` 修改金币变量，然后再写主角拿着东西回家的正文。
4. 沿用已有的同名变量，不要擅自改名；数值计算以「当前变量清单」里的现值为准。
5. 多个操作按从上到下顺序执行；同批可叠加。
6. **`value` 必须是严格 JSON**：布尔写小写 `true` / `false`，字符串必须带双引号 `"..."`。「当前变量清单」里的 `True` / `False`（大写，Python 风格）只是现值展示，**不是**要你写进 JSON 的字面量——写布尔时一律小写。

## 当前可维护变量清单

在修改以下变量时你需要生成 JSON，以下是这些变量的名字、当前值、和说明：

```yaml
- name: user
  value: ${user}
  note: 玩家主控角色的名字
- name: user所在地
  value: ${user所在地}
  note: 主角当前所在地。在主角移动之后需要用`set`更新此变量。
```

${!-- 维护说明（导演可见，正文 bot 看不到）：在此按实例实际变量增删清单行；${变量名} 是占位符，Generate 发送前会自动展开为当前值，正文 AI 据此计算。变量名必须与 .teahouse/runtime_vars.jsonl 中的实际名字一致，否则操作会落到不存在的变量上。 --}
