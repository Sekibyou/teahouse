# 静态设定（随实例入 git，不建议修改）

本目录存放**长期稳定、不随剧情变化**的静态设定，一般包括三类：

1. **固定不变的设定**：正文生成标准、宏观设定、世界观常量等，全剧恒定。
2. **分阶段设定**：按变量值动态切片——用条件占位符（`${@condition ...}` / `${@python ...}`）按变量现值就地选取对应阶段，如修为分段、好感度阶梯提示词。
3. **动态设定的模板**：某类事物的设定模板（如"某类型的人物的设定模板"）。游玩过程中导演或总结功能按需读取模板 → 在 `settings/dyn_settings/` 内创建一个真正的设定实例。

规则：
- **随实例 git 版本控制**（与 `settings/dyn_settings/` 同仓提交）。它应稳定存在。
- **不建议由导演/总结修改**。剧情推进需要更新的、以及模板物化出的实例，都放 `settings/dyn_settings/`（动态设定）。

需要引用本目录内容时，用占位符切片，例如 `{{settings/static_settings/剧情阶段.md|from="<第一章>"|to="</第一章>"}}`。
