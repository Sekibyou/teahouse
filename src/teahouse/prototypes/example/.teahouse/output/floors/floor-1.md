# 第一章 · 边陲小镇灰石镇

黄昏时分，一辆驮满杂货的老马车碾过镇口那条被车辙磨得发亮的石板路。车轮吱呀作响，惊起檐下几只灰雀，扑棱棱飞上围栏，又转头好奇地打量这辆进城的外乡车。

${user}从车尾跳下来，脚踩上积了一层薄灰的石板，拍了拍身上的尘土，背起行囊，站在镇口那棵歪斜的老槐树底下，抬头打量这座被称为「灰石镇」的边境小镇。

镇子不大。拢共就一条主街，从镇口的槐树下直直通到镇西头的冒险者公会，两头各立着一盏锈迹斑斑的铁皮灯。两旁的木屋有些年头了，墙皮剥落的地方露出灰褐色的原木纹路，屋檐下挂着风干的老玉米和几串红辣椒，被晚风荡得轻轻摇晃。街角的告示栏上贴着几张泛黄的悬赏纸，大多已经卷了边，被风掀起一角，露出底下模糊的字迹。

暮色像一层薄灰，从山那边慢慢地漫过来。街上行人不多，几个孩童追着一只跑偏的毛驴笑闹，被路旁妇人拎着耳朵拽了回去。远处有铁匠铺里叮叮当当的打铁声，混着若有若无的烟火气，把这座边陲小城裹进一片安详又有些寂寥的黄昏中。

他站在街口，一时没有急着进镇。这座小镇实在没什么特别之处——唯一的谈资，便是镇后那座黑黢黢的山脊轮廓底下，传说里让整个边境都闻名的那座地牢。他这一路见过不少热闹的商埠，也路过几座荒废的村落，唯独像灰石镇这样，把「靠一座地牢吃饭」写在门楣上的地方，还是头一遭。
